## 一、单页爬取的通用四步

```
请求(request) → 解析(parse) → 提取(extract) → 存储(store)
```

1. **请求**：拿到网页 HTML(用 `requests.get`)。
2. **解析**：`BeautifulSoup(html, "lxml")` 变成可查询对象。
3. **提取**：`select` / `xpath` 取出每一条数据，整理成字典列表。
4. **存储**：写进 CSV / 数据库。

> 这个四步模式是爬虫的**基本骨架**。后面所有复杂爬虫都是在这四步的每个阶段加了东西（循环、并发、异常处理等），核心逻辑不变。

> 真实落地只要把 `io.StringIO()` 换成 `open("books.csv", "w", newline="", encoding="utf-8")`，其余写法完全一致。`newline=""` 能避免 Windows 下多出空行。

### CSV 写入对比

| 方式 | 适用场景 | 优点 | 缺点 |
| --- | --- | --- | --- |
| `io.StringIO()` + `getvalue()` | 浏览器练习、内存操作 | 不写文件，即跑即用 | 数据在内存里，关了就没了 |
| `open("file.csv", "w")` | 本地真实运行 | 数据落盘，永久保存 | 需处理编码、换行 |

## 四、完整单页爬取流程（含 requests）

下面是一个**完整**的单页爬取示例——从请求到存储一条龙。注意每个步骤的异常处理：

```python
import requests
from bs4 import BeautifulSoup
import csv

url = "https://books.example.com/list"
headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)..."}

# 步骤 1: 请求
try:
    resp = requests.get(url, headers=headers, timeout=5)
    resp.raise_for_status()
except requests.exceptions.RequestException as e:
    print("请求失败:", e)
    exit(1)

# 步骤 2: 解析
soup = BeautifulSoup(resp.text, "lxml")

# 步骤 3: 提取
books = []
for li in soup.select(".books li.book"):
    books.append({
        "title": li.select_one(".title").get_text(strip=True),
        "price": li.select_one(".price").get_text(strip=True),
    })

print(f"抓到 {len(books)} 本")

# 步骤 4: 存储 CSV
with open("books.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["title", "price"])
    writer.writeheader()
    writer.writerows(books)

print("已保存 books.csv")
```
